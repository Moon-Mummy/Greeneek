### Gap Summary

- **Missing / UX-only (≈27 rows)**: mostly local-first PAL, thread persistence, reasoning/vision/files, presets, a11y/responsive polish.
- **Blocked by architecture decision** before UI can land correctly: PAL interfaces + provider registry SSOT + stores + storage. Hence the plan phases below.
