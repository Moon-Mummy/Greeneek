# Internationalization — Status & Pipeline

## Structure

- Locale bundles: `packages/web/src/locales/{en,es}.ts` (ICU-ready string
  records; plurals can be added via `tDict[lang][key]`).
- Language switcher: header button + persisted `gk.lang`.
- RTL: all layout uses CSS logical spacing on `:root` tokens, so an RTL
  bundle (`ar`, `he`) only needs locale text + `dir="rtl"`.

## Remaining hard-coded strings (audit)

Tracked list to zero out before launch:

- [ ] Terminal gutter line numbers (visual, not translatable)
- [ ] Tool names/descriptions (technical identifiers, kept in English)
- [ ] Server-side log lines (developer-facing)

## Translation pipeline

- In-house: edit locale `.ts`, run `pnpm test`, screenshot reviewer.
- Crowdin-ready: locale files export/import as JSON; the key surface is
  `t(lang, key)`, so no component rewrites are needed to add languages.
