# Greeneek Brand Guidelines

The Greeneek visual system is the **Technical Precision System**: Corporate /
Modern, information-dense, editorial-clean. It evokes "surgical tools for AI"
— reliable, fast, intellectually rigorous. Sub-pixel hairlines, superellipse
corners, deep slate tonal foundation.

## Name & voice

- Product: **Greeneek** — one word, capital G, lowercase rest.
- CLI binary: `greeneek`
- Package scope: `@greeneek`
- Maintainer: **Greeneek Labs**
- Voice: authoritative, precise, transparent. No decorative clutter.

## Colors

- Primary — Brand Ink `#0F1115`: buttons, focal text, structure.
- Secondary — Forest Emerald `#067A52`: interaction, active states,
  progress. Dark mode shifts to luminous `#34D399`.
- Tertiary — Slate Gray `#61666B`: metadata, supporting chrome.
- Surfaces — technical grays; dark foundation `#151517`.

Full token tables, typography scale, spacing rhythm, radii, elevation and
component rules live in `docs/design-system.md` and the shipped
`@greeneek/brand` tokens.

## Assets

- `packages/brand/assets/logo-mark.png` — primary mark
- Wordmark: logo + Inter 700 wordmark.

## Don'ts

- Do not use upstream marks, names, or assets.
- Do not recolor the emerald to blue.
- Do not exceed the 4px rhythm.
